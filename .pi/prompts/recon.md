---
description: 정책과 승인 절차가 적용되는 리콘 실행을 시작한다
---

사용자에게 딱 두 가지만 묻는다: 1) 허용 도메인, 2) 프로그램이 Gobuster·Parameth 같은 대량 요청 도구를 허용하는지 여부. 특정 단계나 도구 요청이 없으면 `recon_start`로 전체 실행한다. 특정 항목만 요청했다면 `recon_create` 후 `recon_run`으로 그것만 실행한다. 기존 run ID가 주어지면 새 run을 만들지 않는다. 완료되면 짧은 결과 요약과 run ID만 알려준다.

요청된 스코프 입력: `${ARGUMENTS:-제공되지 않음}`
