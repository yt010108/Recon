# Selected SecLists files

This directory contains only the two SecLists files currently consumed by the
recon harness:

- `web-common.txt`: `Discovery/Web-Content/common.txt`
- `dns-5000.txt`: `Discovery/DNS/subdomains-top1million-5000.txt`

They were copied from the Kali `seclists` package version recorded in the parent
workspace's `tools.yaml`. The package copyright and license notice is preserved
in `COPYRIGHT`. Source project: <https://github.com/danielmiessler/SecLists>.

The small project-owned `../params-small.txt` remains the Parameth default.
